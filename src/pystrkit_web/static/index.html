生成 URL slug POST /api/text/slug

中文会被移除——拼音转换需要额外依赖，本库刻意不做。需要拼音请先过一遍 pypinyin。

设计取舍：格式不合法时原样返回、不抛异常。因为脱敏跑在日志和展示链路上， 一条脏数据不该打断整条请求。代价是你必须看 valid 字段才知道到底脱没脱成。

全文扫描脱敏 POST /api/mask/scan

从一段正文里捞出所有手机号与身份证号并打码。顺序是先身份证后手机号—— 18 位身份证号里天然含 11 位连续数字，反了会被手机号规则拦腰截断。

人民币转中文大写 POST /api/money/rmb

财务口径：先转 Decimal 再量化到分，四舍五入用 ROUND_HALF_UP。 传字符串最安全——直接传 float 会带进 0.1+0.2 那类误差。

标准 整数 角位为零 负数 亿级 非法（报错）
和脱敏相反，金额解析失败会直接抛错。 因为金额跑在财务链路上，静默吞掉一个解析错误，等于开错一张发票。 同样是「出错」，两条链路两种策略，这是刻意的设计。

批量逐行转换 POST /api/batch

每行一行输入，逐行转换。单行失败不会中断整批，失败行标红并显示原因。
